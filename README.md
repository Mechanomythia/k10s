# k10s

A native macOS app for Kubernetes: what k9s does, in a SwiftUI window, across several clusters at once.

- Everything kubectl does: browse every resource kind (CRDs included), describe, YAML, events, logs, exec, port-forward, scale, restart, edit, delete.
- Multi-context: list, for example, all Deployments in several clusters in one view, and switch between contexts in tabs.
- The hyad design system, like iris.

Status: planning. Nothing to build yet.
